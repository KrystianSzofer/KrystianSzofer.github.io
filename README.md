# Portfolio (Work in Progress)

Das ist das offizielle Repo für meine Portfolio Website "KrystianSzofer.github.io".

## Rendering
Die gewählte Renderingmethode ist Static Site Generation (SSG). Folgende Faktoren haben meine Entscheidung mitunter beeinflusst: 
- eine Portfolio Website benötigt im Regelfall keine Updates
- Geschwindigkeit (HTML beretis zu Build Zeit generiert)
- gute Sicherheit (kein Backend das angegriffen werden kann sowie allgemein ein komplexes Gebiet, das dadurch vereinfacht wird)
- kostenloses Hosting auf Github

## Framework
Das zugrunde liegende Framework ist Angular. Da ich zurzeit meine Kenntnisse stetig ausbaue, Angular sehr gefragt in der Industrie ist und SSG von Angular unterstützt wird, fiel mir die
Entscheidung leicht.

Da ich bereits Erfahrungen mit Angular Material gesammelt habe, entschied ich mich dieses Mal auf solche UI-Komponenten Libraries zu verzichten. Der Fokus lag auf der Implementierung 
von eigenen Komponenten, um meine CSS Fähigkeiten zu vertiefen sowie zu testen. 

## Lernerfahrung 

Das war die erste SSG Website, die ich gebaut habe, wodurch ich zuerst Probleme mit Github Actions hatte. Nun verstehe ich viel besser wie das Deployment solch einer Website funktioniert. 

Die Website habe ich eigenständig entworfen - meine Figma Fähigkeiten sind bereits fortgeschritten, aber mit dem Entwurf an sich war ich sehr zufrieden. Auch habe ich mir viel Gedanken,
um Animationen gemacht, um die Website lebendiger und anspruchsvoller wirken zu lassen. Aber mir ist auch schnell die Frage aufgekommen: Wann ist es zu viel? Denn es sieht zwar besser aus,
aber ist nicht automatisch dadurch mehr usability freundlich.
